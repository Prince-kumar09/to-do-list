# To-Do List App 

A simple and user-friendly To-Do List application that helps users manage their daily tasks and stay organized.

##  Features

- Add new tasks
-  Mark tasks as completed
-  Delete tasks
-  View and manage daily tasks
-  Simple and clean user interface

##  Technologies Used

- HTML
- CSS
- JavaScript

##  Project Structure

```text
To-Do-List/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

##  How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start adding and managing your tasks.

## Project Objective

The objective of this project is to practice HTML, CSS, and JavaScript by building a practical application for managing everyday tasks.

##  Future Improvements

- Save tasks using Local Storage
- Add task deadlines
- Add task filters
- Make the application responsive for mobile devices
